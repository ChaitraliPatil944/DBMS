## Key Revision Points

- A database is an organized collection of related data.
- A DBMS is software that stores, manages, secures, and retrieves data.
- Data consists of raw facts, while information is processed and meaningful data.
- DBMS overcomes the limitations of traditional file systems by reducing redundancy and improving consistency.
- Important DBMS characteristics include data independence, security, integrity, concurrency, and backup & recovery.
- Common database types include Relational, NoSQL, Distributed, Cloud, Hierarchical, Network, and Object-Oriented databases.
- Database users include DBAs, designers, developers, analysts, and end users.
- The DBA manages security, backups, recovery, performance tuning, and user access.
- Major DBMS components are the Query Processor, Storage Manager, Transaction Manager, Recovery Manager, Database Engine, and Data Dictionary.
- The Three-Schema Architecture consists of External, Conceptual, and Internal levels, providing logical and physical data independence.
- DBMS is widely used in banking, healthcare, education, e-commerce, government, airlines, and social media.
