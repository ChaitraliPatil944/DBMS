# Section D: Multiple Choice Questions

## 1.
Which software is used to manage databases?

A. Compiler
B. DBMS
C. Browser
D. Operating System

**Answer:** B

---

## 2.
Which of the following is an example of an RDBMS?

A. MySQL
B. MS Paint
C. VLC
D. Photoshop

**Answer:** A

---

## 3.
Which database user is responsible for backup and recovery?

A. End User
B. Application Developer
C. DBA
D. Tester

**Answer:** C

---

## 4.
Which schema represents the physical storage of data?

A. External
B. Conceptual
C. Internal
D. Logical

**Answer:** C

---

## 5.
Processed data is called:

A. Metadata
B. Information
C. Record
D. Field

**Answer:** B

# Section E: True or False

1. A DBMS reduces data redundancy. **True**
2. Information is raw facts. **False**
3. The DBA manages database security. **True**
4. The Internal Schema describes physical storage. **True**
5. File systems provide better concurrency than DBMS. **False**
