# Practice Exercises – Database Architecture

This lesson provides exercises to help you revise and strengthen your understanding of database architectures. The exercises include multiple-choice questions, short-answer questions, long-answer questions, comparison-based questions, and practical scenarios.

---

# Section A: Multiple Choice Questions (MCQs)

## Choose the correct answer.

1. Which architecture stores the application and database on the same machine?
   - A. Two-Tier
   - B. Three-Tier
   - C. One-Tier
   - D. Distributed

**Answer:** C

2. Which architecture introduces an application server?
   - A. One-Tier
   - B. Two-Tier
   - C. Three-Tier
   - D. Centralized

**Answer:** C

3. Which architecture provides the highest scalability?
   - A. One-Tier
   - B. Cloud Database
   - C. Two-Tier
   - D. File System

**Answer:** B

4. Which architecture is best for enterprise applications?
   - A. One-Tier
   - B. Three-Tier
   - C. Standalone
   - D. File-Based System

**Answer:** B

5. Distributed databases improve:
   - A. Fault tolerance
   - B. Availability
   - C. Scalability
   - D. All of the above

**Answer:** D
