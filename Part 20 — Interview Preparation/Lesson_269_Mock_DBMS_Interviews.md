# Lesson 269 - Mock DBMS Interviews

**Part:** Part 20 – Interview Preparation

**Difficulty:** Placement Focus  
**Interview Frequency:** ⭐⭐⭐⭐⭐

---

# Learning Objectives

- Experience realistic DBMS interview questions.
- Practice answering under time pressure.
- Learn what interviewers expect in strong answers.
- Improve confidence before placements.

---

# 1. Introduction

Mock interviews simulate real technical interviews by combining theory, SQL, design, and scenario-based questions.

Treat each question as if you are speaking to an interviewer.

---

# Mock Interview 1 - Basic (10-15 Minutes)

## Questions

1. What is DBMS?
2. DBMS vs RDBMS?
3. Explain Primary Key and Foreign Key.
4. Difference between DELETE, DROP, and TRUNCATE.
5. What is normalization?
6. Explain ACID properties.
7. What are joins?
8. Difference between WHERE and HAVING?
9. What is an index?
10. Why use transactions?

Evaluation:
- Concept clarity
- Confidence
- Communication

---

# Mock Interview 2 - Intermediate (20 Minutes)

## Questions

1. Explain 1NF to BCNF.
2. Clustered vs Non-Clustered Index.
3. What is deadlock?
4. Explain isolation levels.
5. How does B+ Tree indexing work?
6. Write a query for the second highest salary.
7. Explain execution plans.
8. What is partitioning?
9. Replication vs Sharding.
10. SQL vs NoSQL.

Evaluation:
- Technical depth
- SQL skills
- Trade-off discussion

---

# Mock Interview 3 - Advanced (30 Minutes)

## Scenario Questions

### Scenario 1

A banking application is slowing down.

How would you investigate?

Expected discussion:

- Execution plans
- Indexes
- Locks
- Transactions
- Monitoring

---

### Scenario 2

Design a database for an online food delivery system.

Discuss:

- Tables
- Relationships
- Indexes
- Transactions
- Scalability

---

### Scenario 3

Your application suddenly receives ten times more traffic.

Possible improvements:

- Replication
- Sharding
- Caching
- Load balancing
- Auto scaling

# Self-Evaluation Checklist

Rate yourself (1-5):

- Concept clarity
- SQL knowledge
- Communication
- Confidence
- Problem solving
- Time management

Identify weak topics and revise them before the next mock interview.

---

# Interview Insights ⭐

- Answer in a structured manner.
- Use examples whenever possible.
- Explain trade-offs.
- Clarify assumptions for scenario questions.

---

# Interview Traps 🚨

- Giving memorized definitions without understanding.
- Ignoring performance implications.
- Jumping to conclusions without asking clarifying questions.
