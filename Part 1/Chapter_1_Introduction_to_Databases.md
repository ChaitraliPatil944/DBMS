
# Part 1 – Database Fundamentals
# Chapter 1 – Introduction to Databases

## Goal
Understand what a database is, why databases exist, and build a strong foundation for DBMS.

## 1. What is Data?
Data is a collection of raw, unprocessed facts.

Examples:
- Chaitrali
- 95
- Pune
- 21

## 2. What is Information?
Information is processed and meaningful data.

Example:
> Chaitrali scored 95 marks in DBMS and lives in Pune.

## 3. Data vs Information

| Data | Information |
|------|-------------|
| Raw facts | Processed facts |
| No context | Meaningful |
| Input | Output |

## 4. What is a Database?
A database is an organized collection of related data stored electronically for efficient access, management, updating, and security.

### Applications
- Banking
- Hospitals
- Colleges
- E-commerce
- Social media

## 5. Why Do We Need Databases?
- Reduce duplication
- Improve security
- Faster searching
- Multi-user access
- Backup & recovery

## 6. Library Analogy
- Books = Data
- Catalog = Database
- Librarian = DBMS
- Reader = User
